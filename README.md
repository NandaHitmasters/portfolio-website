# Nanda Kishore Panem Venkata - Portfolio Website

Welcome to my personal portfolio website! This project is a showcase of my professional experience, skills, and background as a Full Stack Lead and Architect.

## Tech Stack
* **Structure:** Semantic HTML5
* **Styling:** Vanilla CSS (Modern CSS variables, `light-dark()` theme switching, and glassmorphism cards)
* **Interactions:** Vanilla JavaScript (Search-hidden-content tab panels and scroll-driven entry animations)
* **Dev Tools:** Vite development server and builder

## Sections Included
1. **Hero Header:** Direct contact links (LinkedIn, Email) and current status.
2. **About Me:** Core experience summary with quick highlights.
3. **Experience Timeline:** Tabbed interface detailing roles at Hitmaster Graphics, PayPal, Altimetrik, and more.
4. **Core Competencies:** Categorized skills grid (Frontend, Backend, Architecture & Cloud).
5. **Education & Languages:** Degree details and multilingual proficiencies.
6. **Contact Me:** Secure connection cards.

## Local Development
To run this project locally, make sure you have [Node.js](https://nodejs.org/) installed, then run:

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
